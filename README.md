# Покерная раздача карт

Небольшой учебный проект на React и TypeScript. Приложение создаёт колоду из 52 карт, раздаёт пять случайных карт без повторов и определяет комбинацию.

## Возможности

- Создание колоды из четырёх мастей и тринадцати достоинств.
- Раздача пяти карт по нажатию кнопки.
- Определение комбинации:
    - старшая карта;
    - одна пара;
    - две пары;
    - тройка;
    - флэш.
